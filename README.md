# Çok Emin Yanlış Hesap Makinesi

## Bu Nedir?

Bu, evrenin en ciddi, en emin ve en yanlış çalışan hesap makinesidir. 

Normal hesap makineleri 2+2=4 der. Ama onlar yanılır. Biz yanılmayız. Biz çok eminiz ki 2+2 aslında 5'tir. Veya 7. Veya o anki ruh haline göre.

Bu proje, bilimsel yöntemleri (yani rastgele sayı üretmeyi) kullanarak matematiksel gerçekleri yeniden tanımlar. 

**Uyarı:** Bu kodu gerçek hayatta kullanmayın. Kullanırsanız da suçu bize atmayın. Biz çok eminiz ki suçlu değiliz.

## Nasıl Çalışır?

1. Python ile çalıştır.
2. İki sayı gir.
3. Kod uzun uzun düşünür, emindir, sonra yanlış cevap verir.
4. Sen de "Evet, mantıklı" dersin. Çünkü kod çok emin.

## Özellikler

- Her zaman yanlış cevap (garanti)
- Dramatik bekleme süreleri (gerçek hesaplama gibi)
- Türkçe abartılı açıklamalar
- Hiçbir işe yaramaz ama çok çalışır
- Bilimsel kanıt yok ama çok var gibi hissettirir

## Kurulum

```bash
pip install nothing  # hiçbir şey gerekmez, zaten yanlış çalışıyor
python hesap_makinesi.py
```
